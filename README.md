# AdventureWorksLT-sales-Power BI dashboard
## Objective
To analyze and present AdventureWorksLT sales data effectively using Power BI through data connection, shaping, combining, and visualization techniques.

## Questions
1--> What are the trends in LineTotal across different categories and states?

2--> How can sales insights be leveraged to identify top-performing products and companies?

3--> What geographical sales patterns emerge at city and state levels?

## Process
Data Connection: Import AdventureWorksLT database queries (Labexercise1.SQL Task 1 and Task 2) and load them into Power BI.

Data Shaping: Refine and rename tables, delete unnecessary columns, and hide irrelevant fields. Create calculated columns and measures (e.g., FullAddress, LineTotal, TargetSales) for enriched analysis.

Data Combination: Import state data from Wikipedia, clean it, merge with sales data, and structure it for clarity.

Visualizations: Develop a range of visuals (gauge, pie, stacked charts, maps) to present key metrics like TargetSales, LineTotal, and OrderQty.

## Insights
The LineTotal and TargetSales measure offer valuable benchmarks to assess company and category performance.

Geographical visualizations spotlight key cities and states contributing to total sales, aiding strategic planning.

Filters and calculated measures provide precise data segmentation for actionable insights.

## Conclusion
The Power BI dashboard successfully integrates and visualizes AdventureWorksLT sales data to uncover meaningful insights. By leveraging calculated measures, advanced filters, and interactive visuals, the project demonstrates an effective approach to data analysis and decision support. This dashboard empowers users to explore sales trends, identify key products, and make informed strategic choices."
